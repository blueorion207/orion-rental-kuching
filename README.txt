ORION RENTAL KUCHING — MVP STARTER

This is the first frontend foundation for the approved website specification.
It is NOT the completed booking system and is not ready to publish as a live booking website.

Included:
- Responsive mobile-first homepage
- Approved navy/teal colour direction
- Automatic/light/dark theme foundation (manual light/dark toggle currently)
- English/Bahasa Malaysia language switch
- Fleet cards with the approved daily rates
- WhatsApp enquiry links
- Basic About and Contact sections

Important next development stages:
1. Build separate Fleet/Vehicle Details, FAQ, Contact, About, T&C and Privacy pages.
2. Implement the full four-step booking flow and all approved pricing/validation rules.
3. Add cookie consent, SEO metadata/schema, accessibility and analytics consent controls.
4. Replace illustrative emoji placeholders with owner-supplied logo and verified fleet photos.
5. Test thoroughly before deployment.

To preview:
- Extract the ZIP.
- Open index.html in a modern browser.
- For deployment, upload the folder contents to a static web host.

Do not treat a WhatsApp enquiry link as a confirmed booking. Availability and booking confirmation remain manual.
